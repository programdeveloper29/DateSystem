# 📅 Date System (C# Console Application)

## 📌 Overview

This project is a simple **Date Management Console Application** built using **C#**.

The goal of this project is to practice:

* Object-Oriented Programming (OOP)
* Constructor Overloading
* Data Validation
* Working with Arrays
* Clean Input/Output Handling

---

## 🏗️ Project Structure

### 🔹 Date Class

Represents a date with:

* Day
* Month
* Year

### ✔ Features:

* Validate correct date values (including leap years)
* Multiple constructors:

  * Full date (day, month, year)
  * Month & Year
  * Year only
* Formatted output (DD/MM/YYYY)

---

### 🔹 Program Class

Handles:

* User input
* Creating date objects
* Printing results

---

## ⚙️ Features

### ✅ Create Dates in Different Formats

User can choose:

1. Full Date → (Day / Month / Year)
2. Month & Year
3. Year only

---

### ✅ Validation

* Checks valid numbers using `TryParse`
* Ensures:

  * Valid day per month
  * Leap year handling

---

### ✅ Output Formatting

Dates are displayed in this format:

```id="a7d92x"
DD/MM/YYYY
```

Example:

```id="k3l8as"
01/02/2024
```

---

## 🧠 Concepts Applied

* 🔹 Constructor Overloading
* 🔹 Encapsulation
* 🔹 Arrays of Objects
* 🔹 Input Validation
* 🔹 Conditional Logic
* 🔹 Basic Error Handling

---

## ▶️ How to Run

1. Open the project in **Visual Studio**
2. Run the application
3. Choose the date type:

   * `1` → Full Date
   * `2` → Month & Year
   * `3` → Year Only
4. Enter number of dates
5. Input values
6. View formatted output
